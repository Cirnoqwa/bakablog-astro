<mark style="background-color:#FFB6C1;padding:4px 10px;border-radius:6px 6px 6px 6px;color:white;font-weight:bold;">一、使用关系图</mark>

:::note
**两种使用方式（任选其一）**

**方式一（推荐）：通过 `graph` 属性自动加载数据**
```mdx
// 在 .mdx 文件顶部导入组件
import Graph from '../../components/Graph.astro';

// 在正文任意位置使用，graph 指定 JSON 文件名（自动去 .json）
<Graph graph="links" id="myGraph" showLabel={true} />
```
- `graph` 属性值对应 `public/data/Graph/` 目录下的 JSON 文件（不含 `.json` 后缀，带也行）。
- 组件会在客户端自动请求 `/api/graph?board=links` 获取数据，无需手动 `import`，彻底解决构建路径问题。

**方式二（兼容旧版）：通过 `data` 属性传入数据**
```mdx
import Graph from '../../components/Graph.astro';
import graphData from '/data/Graph/links.json';   // 需要配置 Vite 别名（不推荐）

<Graph data={graphData} id="links" showLabel={false} />
```
> 旧方式需自行配置 Vite 别名将 `/data` 映射到 `public/data`，**新方式无需任何配置**，更简单可靠。

**参数说明**
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `graph` | `string` | `'links'` | JSON 文件名（自动去 `.json`），组件会调用 `/api/graph?board=xxx` 加载 |
| `data` | `object` | – | 直接传入数据对象，若同时提供 `graph` 和 `data`，优先使用 `data` |
| `id` | `string` | `'main'` | 容器 ID，同一页面多个图表需唯一 |
| `showLabel` | `boolean` | `true` | 是否默认显示节点/边标签 |

---

**JSON 数据格式**
将关系图数据保存在 `public/data/Graph/` 目录下，例如 `links.json`，格式如下：
```json
{
  "categories": [
    { "name": "根", "color": "#74D1EA" },
    { "name": "友情链接", "color": "#39C5BB" },
    { "name": "子友情链接", "color": "#A0AEC0" }
  ],
  "nodes": [
    { 
      "id": "self", 
      "name": "Cirno_qwa 的博客", 
      "symbolSize": 60, 
      "category": 0,
      "color": "#74D1EA", 
      "icon": "/Graph/links/avatar.jpg",
      "info": "Cirno_qwa制作"
    },
    { 
      "id": "marblemc", 
      "name": "大理石网", 
      "symbolSize": 45, 
      "category": 1,
      "color": "#39C5BB",
      "icon": "/Graph/links/marblemc.png",
      "info": "Romarku开发。<br/><a href='https://marblemc.cn' target='_blank'>点击访问</a>"
    }
  ],
  "links": [
    { "source": "self", "target": "marblemc", "value": "友情链接", "info": "么么哒,Romarku" },
    { "source": "self", "target": "brial", "value": "友情链接", "color": "#74D1EA" }
  ]
}
```

**字段说明**
- `categories`：分类数组，`color` 用于图例和节点默认颜色（可选）。
- `nodes`：节点数组。
  - `id`：**必须**，节点唯一标识。
  - `name`：显示名称。
  - `symbolSize`：圆点大小（数值越大越大）。
  - `category`：数字，对应 `categories` 的下标（从 0 开始）。
  - `icon`：图片 URL（如 `/img/logo.png`），节点将显示为图片。
  - `color`：节点颜色（支持 CSS 颜色值）。
  - `info`：悬浮提示（支持 HTML）。
- `links`：边数组。
  - `source` / `target`：节点的 `id`。
  - `value` / `label`：边上显示的文字。
  - `color`：线条颜色。
  - `info`：悬浮提示（支持 HTML）。

---

**示例**

<div style="margin: 20px 0;">
  <h3 style="font-size: 14px; margin-bottom: 10px; color: #64748b;">🔗 关系图</h3>
  <Graph graph="guides_test" id="example" showLabel={false} />
</div>

**更新说明**
- **新版 `graph` 属性**：无需 `import` 数据，组件自动请求 `/api/graph`，彻底消除构建路径问题。
- **完整交互保留**：缩放、拖拽、标签切换、深色/浅色主题自适应、触摸支持，所有功能与旧版一致。
- **兼容性**：同时保留 `data` 属性，旧代码无需修改，但推荐迁移到 `graph` 方式。

> 如有疑问，请参考 [Graph.astro 源码](https://github.com/Cirnoqwa/bakablog-astro/blob/main/src/components/Graph.astro)

<mark style="background-color:#FFB6C1;padding:4px 10px;border-radius:6px 6px 6px 6px;color:white;font-weight:bold;">五、Board 组件快速使用手册</mark><br /> 

:::top
### 引用组件
在 `.astro` 页面中引入并引用：
```astro

import Board from "src/components/Board.astro"; //引入

<Board board="th.json" sort="votes-desc" /> //使用排行榜
```
:::

:::important
### 修改引用值
- **`board`**：对应 `src/data/Board/` 下的 JSON 文件名（可带 `.json` 后缀，也可不带）。修改此值可切换不同榜单。
- **`sort`**：默认排序方式，支持以下值：
  - `votes-desc`（票数高→低，**默认**）
  - `votes-asc`（票数低→高）
  - `alpha-asc`（名称 A→Z）
  - `alpha-desc`（名称 Z→A）
  - `date-desc`（最新在前）
  - `date-asc`（最早在前）
:::

### JSON 数据格式
每个榜单一个 JSON 文件，存放在 `src/data/Board/`，结构如下：

```json
{
  "title": "东方Project人气角色排行榜",
  "showAvatar": true,
  "defaultDotColor": "#FFB6C1",
  "items": [
    {
      "id": "1a2b3",
      "title": "博丽灵梦",
      "votes": 1024,
      "createdAt": "2025-01-01T00:00:00Z",
      "ips": [],
      "avatar": "reimu.jpg",
      "dotColor": ""
    },
    {
      "id": "4c5d6",
      "title": "雾雨魔理沙",
      "votes": 987,
      "createdAt": "2025-01-02T00:00:00Z",
      "ips": [],
      "avatar": "marisa.jpg",
      "dotColor": ""
    },
    {
      "id": "7e8f9",
      "title": "十六夜咲夜",
      "votes": 856,
      "createdAt": "2025-01-03T00:00:00Z",
      "ips": [],
      "avatar": "",
      "dotColor": "#C0C0C0"
    },
    {
      "id": "a1b2c",
      "title": "蕾米莉亚·斯卡蕾特",
      "votes": 812,
      "createdAt": "2025-01-04T00:00:00Z",
      "ips": [],
      "avatar": "",
      "dotColor": "#DC143C"
    }
  ]
}
```
:::important
**字段说明：**
- `title`：榜单标题（可选）
- `showAvatar`：是否显示头像（`true`/`false`）
- `defaultDotColor`：默认圆点颜色（CSS 颜色，无头像时使用）
- `items`：榜单项目数组，每个项目需包含：
  - `id`, `title`, `votes`, `createdAt`, `ips`（系统维护）
  - `avatar`：头像文件名，需放在 `public/Board/{board}/` 下
  - `dotColor`：该项目专属圆点颜色，优先级高于默认色
:::

:::important
如果想创建个新json表,初始内容可以为:
```json
{
  "title": "我的榜单",
  "showAvatar": false,
  "defaultDotColor": "#d3d3d3",
  "items": []
}
```
或者最简单:
```json
{
  "items": []
}
```
